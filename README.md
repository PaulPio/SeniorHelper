# SeniorHelper
This project made to helper elderly people to remember their appointments, when to take their pills and other miscellaneous topics such as cheking the weather.

Technology used
Frontend: HTML, CSS, JavaScript.
The front end was made in a way that would not look excesivly complicated in an attempt to make it as easy to understand to elderly people. This was complemented with the soft blue colors that should not prove to strainful to those looking at the chatbot. This is also built upon with the thinking indicators as well as the error indications to make it easier to show what the chatbot is doing or if a new prompt needs to be submitted.

Backend: Python
